A files backend: ``Backend.open("~/.calendars")``, a ``file:`` URL, or a section with a path as its ``url``.  It reads and writes a vdir as vdirsyncer, khal and todoman lay it out (a root of collection directories, or one collection directory) and a single ``.ics`` file, with atomic writes, a lock around each write to a single file, and etags that catch a file edited behind its back.  In the async mode, file I/O runs in worker threads.  It passes the conformance suite in all three layouts.
